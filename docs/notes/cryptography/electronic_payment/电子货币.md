# 电子货币

> 来源：`密码学引论 / electronic_payment/电子货币.md`

电子货币是以电子方式表示和转移价值的支付形态。密码学在其中主要解决认证、防伪、隐私保护、双花检测和账本一致性问题。

## 两条技术路线

- 账户型电子货币：重点是确认账户身份和交易授权，例如银行卡网络、[SET协议](SET协议.md)、[3D-Secure](3D-Secure.md)。
- 现金型电子货币：重点是确认“钱本身”合法，同时尽量保护付款者隐私，例如 [E-cash](E-cash.md)。

## 与区块链的关系

比特币把电子货币问题转化为公开账本的一致性问题：通过工作量证明选出记账者，通过最长链原则处理分叉，通过数字签名证明交易授权。
