## 选择排序
最简单的就是在固定每个位置，然后从后面选择更小的
选择排序（Selection Sort）是一种简单直观的排序算法，无论什么数据进去都是 O(n²) 的时间复杂度。所以用到它的时候，数据规模越小越好。唯一的好处可能就是不占用额外的内存空间了吧。
选择排序基本思想是每次从待排序的数据中选择最小（或最大）的元素，放到已排序序列的末尾，直到全部数据排序完成。
1. **初始化**：将列表分为已排序部分和未排序部分。初始时，已排序部分为空，未排序部分为整个列表。
2. **查找最小值**：在未排序部分中查找最小的元素。
3. **交换位置**：将找到的最小元素与未排序部分的第一个元素交换位置。
4. **更新范围**：将未排序部分的起始位置向后移动一位，扩大已排序部分的范围。
5. **重复步骤**：重复上述步骤，直到未排序部分为空，列表完全有序。
``` C
void selection_sort(int arr[],int len){
	for(int i = 0;i < len;i++)
	{
		int min = i;
		for(int j = i+1;j < len;j++)
		{
			if(arr[j] < arr[min])
			{
				min = j;		
			}
		}
		swap(&arr[i],&arr[min]);
	}
}
```
## Insertion Sort
原地排序
它的工作原理是通过构建有序序列，对于未排序数据，在已排序序列中从后向前扫描，找到相应位置并插入。**插入排序**在实现上，通常采用in-place排序（即只需用到O(1)的额外空间的排序），因而在从后向前扫描过程中，需要反复把已排序元素逐步向后挪位，为最新元素提供插入空间。

需要将序列分为两部分，也是利用双指针，可以用i来表示未排序元素的第一个
然后j是i-1，也就是已排序元素的最后一个
由于是原地排序，\(a[i]\)的位置会发生变化，所以我们得先把\(a[i]\)存起来，不然就找不到了

$$
key = a[i]
$$

然后我们从后往前扫描，如果

$$
a[j] > key
$$

就要把这一部分往右边移动，腾出位置

$$
a[j+1] = a[j]
$$

最差的情况就是j=-1了，那这时候说明已排序的所有元素都比key大，那自然就是第0个位置
也就是令\(a[j+1] = key\)
最好的情况就是\(a[i]\)不动，那还是\(a[j+1]=key\)
一般的情况的话，如果\(a[j] < key\)了，那说明key的位置就应该是\(a[j+1]\)，也还是上面的式子

那为什么不能从前往后扫描？
可以从前往后扫描，但**找到插入位置以后，仍然需要从后往前移动元素**。如果一边从前往后扫描，一边直接右移，就容易覆盖还没有处理的数据。
假设当前数组是：
```text
[1, 3, 5, 7, 4]
 ↑--------↑  ↑
  已排序     key
```
现在需要把 `key = 4` 插入已排序区间 `[1, 3, 5, 7]`。
#### 为什么通常从后往前扫描？
从后往前移动时，元素总是被复制到它右边的位置，而右边的位置已经不再需要保留，因此不会覆盖后面还要使用的元素。
对应代码：

```cpp
for (int i = 1; i < nums.size(); i++) {
    int key = nums[i];
    int j = i - 1;

    while (j >= 0 && nums[j] > key) {
        nums[j + 1] = nums[j];
        j--;
    }

    nums[j + 1] = key;
}
```
#### 从前往后边扫描边移动会怎样？
仍然考虑：1 3 5 7 4
假设从前往后扫描，发现 `5 > 4`，于是立即执行：

```cpp
a[j + 1] = a[j];
```

即：a\[3] = a\[2]
数组变成：13554
原来的 `7` 被覆盖了。
接下来程序再访问 `a[3]`，读到的已经不是原来的 `7`，而是刚刚复制过来的 `5`。因此，不能从前往后一边扫描、一边直接向右覆盖。
本质上，在数组中把一段元素整体向右移动时，必须从右向左复制：

```text
原来：[5, 7, 空位]
移动：[空位, 5, 7]
             ←
```
这与复制有重叠部分的内存类似：
- 整体右移：从后往前复制
- 整体左移：从前往后复制
#### 能否先从前往后找到位置？

可以。例如先从前往后找到 `key` 应该插入的位置：

```cpp
for (int i = 1; i < nums.size(); i++) {
    int key = nums[i];
    int pos = 0;

    // 从前往后寻找插入位置
    while (pos < i && nums[pos] <= key) {
        pos++;
    }

    // 仍然要从后往前移动
    for (int j = i; j > pos; j--) {
        nums[j] = nums[j - 1];
    }

    nums[pos] = key;
}
```

这种写法没有问题，只是分成了两个步骤：
1. 从前往后寻找插入位置；
2. 从后往前移动元素。
而标准插入排序从后往前扫描时，可以同时完成：
- 寻找插入位置；
- 向右移动较大的元素。
因此写法更简洁。

严格来说，这里的 `i` 和 `j` 虽然是两个下标，但通常不把插入排序称为“双指针算法”。`i` 用于划分有序区间和未排序区间，`j` 用于在有序区间内扫描；双指针法通常强调两个指针通过特定移动规则共同缩小搜索范围。
