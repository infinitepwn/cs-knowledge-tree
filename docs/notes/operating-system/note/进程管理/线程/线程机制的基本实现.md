# 线程机制的基本实现

> 来源：`操作系统 / note/进程管理/线程/线程机制的基本实现.md`

相关：[线程](线程.md)、[线程模型](线程模型.md)、[进程](../进程/进程.md)

线程是进程内部的执行流。线程机制的关键，是让多个执行流共享同一进程的资源，同时拥有各自的运行上下文。

## 线程需要保存什么

- 程序计数器 PC：下一条要执行的指令位置。
- 寄存器状态：切换回来后继续运行。
- 栈：保存函数调用、局部变量和返回地址。
- 线程状态：运行、就绪、阻塞等。

## 用户级线程

![image.png](https://raw.githubusercontent.com/infinitepwn/note_picbed/main/20260622214643953.png)


线程管理由用户态线程库完成，内核不知道这些线程的存在。

优点
1. 创建和切换开销小
2. 实现和操作系统无关，调度是由进程内部的实现的
3. 可以在不支持线程的OS平台上实现

缺点
1. 一个线程阻塞可能导致整个进程阻塞(因为只能识别到整个进程，OS会直接阻塞这个进程，)
2. 难以真正利用多核(OS每次只能给整个进程分配CPU，但是线程之间又是并发的，只有一个线程能用到)


简单来说就是程序员自己写，比如python里的多线程
## 内核级线程

线程由操作系统内核管理和调度。

优点是阻塞和调度更灵活，可以利用多核；缺点是创建、销毁和切换需要进入内核，开销更大。
