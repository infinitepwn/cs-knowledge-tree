# 时间片轮转

> 来源：`操作系统 / note/进程管理/调度/时间片轮转.md`

上级：[调度](调度.md)

时间片轮转（Round Robin, RR）是一种面向交互式系统的抢占式调度算法。

系统为每个就绪进程分配一个固定长度的时间片。进程用完时间片后如果还没有结束，就被放回就绪队列末尾，等待下一轮运行。

## 时间片长度

- 时间片太短：[上下文切换](../../概述/上下文切换.md)频繁，系统开销增大。
- 时间片太长：退化为接近[先来先服务](先来先服务.md)，交互响应变差。
