# 内存

> 来源：`操作系统 / note/内存管理/内存.md`

上级：[内存管理](内存管理.md)

内存是程序运行时存放代码和数据的主要存储区域。操作系统负责分配、回收、保护和抽象内存。

## 内存中通常有什么

- 内核代码和内核数据结构。
- 正在运行进程的代码段、数据段、堆和栈。
- 文件缓存和 I/O 缓冲区。
- 页表、进程控制块等管理数据。

用户程序不能直接任意访问整块物理内存。操作系统通过硬件保护机制把用户空间和内核空间隔离开。

## 进程地址空间中的常见区域

- 代码段：保存程序指令，通常只读。
- 数据段：保存全局变量和静态变量。
- 堆：用于动态分配内存，通常向高地址增长。
- 栈：保存函数调用、局部变量和返回地址，通常向低地址增长。

这些区域是进程看到的逻辑布局，实际物理内存中不一定连续。

## 操作系统关心的问题

- 如何为新进程分配内存。
- 如何在进程退出后回收内存。
- 如何阻止越界访问。
- 如何在内存不足时使用[交换](交换.md)或[虚拟内存](虚拟内存.md)。
- 如何减少碎片，提高内存利用率。
